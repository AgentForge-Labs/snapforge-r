## CRAN readiness status

The package is intentionally prepared to pass R CMD check and uses only CRAN
dependencies. Before an actual CRAN submission, replace the placeholder
maintainer address in DESCRIPTION with a monitored address controlled by
AgentForge Labs. No personal maintainer address was available in repository
metadata, so this implementation does not guess or publish one.

R-universe distribution does not require changing the package API or package
contents once that contact field is updated.
